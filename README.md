# Lobios

O **Lobios** é um aplicativo mobile Android desenvolvido em Java, com o objetivo de facilitar a realização de denúncias anônimas no ambiente corporativo.

A aplicação permite que colaboradores registrem ocorrências de forma simples e organizada, informando a categoria e a descrição da denúncia. Após o envio, um protocolo é gerado automaticamente para identificação e consulta do registro.

O projeto foi desenvolvido com foco em simplicidade, acessibilidade e privacidade, oferecendo uma interface intuitiva e uma experiência de navegação adaptada ao Android.

## Funcionalidades
- Registro de denúncias anônimas.
- Seleção de categorias de ocorrência.
- Campo para descrição detalhada.
- Nome do denunciante opcional.
- Geração automática de protocolo.
- Opção para copiar o protocolo.
- Armazenamento local dos registros.

## Tecnologias utilizadas
- Java
- Android
